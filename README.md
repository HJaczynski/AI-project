# AI-project
AI fundamentals project WUT 2024

In order to run our project one need to create own environment: python -m venv venv
Then activate it: ./venv/Scripts/activate.ps1
After that all there is to be done is to install all libraries: pip install -r requirements.txt

After running it and installing all libraries one needs to run the gui.py program

Click on the image(left image) to load pictures, middle one for camera, and the right one for loading videos
